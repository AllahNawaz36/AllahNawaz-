Prime Estimate — SaaS Web App

A SaaS web app concept for an estimating workflow. The interface gives key information, task status, and next steps a clear place on the screen.

My role: Complete UI/UX design, from user flow through to final screens.

Read the case study

Project overview: Prime Estimate is a SaaS web-app design project centred on an estimating workflow. This case study explains the design scope and rationale; it does not claim measured business impact.

Design challenge: Organise an estimating experience so the key information, task status, and next actions are easy to scan and understand.

Approach:

  • Map the flow: Structure the main user journey before detailing individual screens.
  • Prioritise information: Give important estimating information a clear hierarchy and keep supporting details readable.
  • Clarify actions: Make primary actions and task states visually distinguishable to support a predictable workflow.
  • Refine the interface: Carry the flow into final UI screens with consistent spacing, typography, and component patterns.

Design priorities: Workflow clarity, information hierarchy, readable data, consistent interface patterns, and visible next steps.

Deliverable: UI/UX design spanning the user flow and final interface screens.

Outcome and validation: The deliverable is the designed experience. No usability-test results, conversion lift, time savings, or other performance metrics are claimed because verified measurements were not provided.

Conectly — SaaS Application

A SaaS interface designed around straightforward navigation, readable content, and consistent patterns across screens.

Case study overview

Project overview: Conectly is presented as a SaaS application UI/UX project. This overview describes the visible design focus rather than claiming undocumented product features or business outcomes.

Scope shown: Application interface design, with attention to navigation, page structure, and consistency across screens.

Design challenge: Help people orient themselves in an application and recognise where key information and actions belong.

Design approach:

  • Structure navigation: Organise interface sections so the hierarchy is easier to scan.
  • Group information: Use clear content groupings and readable spacing to separate related information.

Design priorities: Navigation clarity, readable hierarchy, consistent components, and a cohesive application experience.

Project framing: An AI-focused influencer-marketing interface concept. This case study discusses the presentation of the concept, not a claim that the pictured capabilities are deployed in a live product.

05 / How I work

A clear process, from start to finish.

I keep the process practical: understand the problem, explore possible solutions, and refine the design with the team.

STEP 01

Understand

Understand the audience, project goals, constraints, and problem to solve.

STEP 02

Explore

Map the user journey, explore ideas, and agree on the structure before refining the visuals.

STEP 03

Design

Design responsive, accessible interfaces with clear layouts and reusable components.

STEP 04

Refine

Review the details, prepare the prototype, and organise the files and notes for developer handoff. User testing is included when agreed in the project scope.
