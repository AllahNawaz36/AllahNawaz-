Local data backup

Because this free dashboard can run without a backend, your leads, tasks, FAQs, drafts and checklists may live only in this browser. Export a backup before clearing browser data or changing devices.

Backup files may contain client contact details. Keep them private. Import replaces the matching local dashboard data.

Data and privacy

Lead storage depends on the backend you configure: the Node option stores JSON on its host filesystem, while the optional Cloudflare Worker stores leads in D1. Local tasks, FAQs, drafts and checklist state remain in this browser. Before real customer use, add a privacy notice, backups, access controls, retention/deletion rules and anti-spam protections.
